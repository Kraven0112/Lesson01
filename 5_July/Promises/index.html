Promise in javascript

A promise is a special type of object which represents the eventual completion of an asynchronous operation and its resulting value.

A promise object is created by browser, so it cannnot use thread of javascript.

It is the way to handle the asynchronous in readable and manageable form in javascript.

Promise always take callback function.

There are three states in promise -- pending,resolve,reject.

Promise is an object which contains promisestate,prototype and promiseResult

When promise is resolved the promisestate is fulfilled.

when the peomise is resolved .then() method is used to control the promise.

when the promise rejected the .catch() method is used to handle the promise.

.then() and .catch() always takes argument of a callback function.

.then() and .catch() return new promise

.catch() provides callback when the promise is rejected

.finally() method is used to settle the promise. it is called event promise is rejected or resolved.

.finally() method does not get data from Promise. It only logs message every promisestate in promise.

.then() .catch() and .finally() are microtasks handle by webAPI not by javascript main thread.
