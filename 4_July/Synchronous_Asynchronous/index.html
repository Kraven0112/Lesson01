Synchronuos and Asynchronous

Synchronous is known as single thread or execute single line at a single time.

Asynchronous is known as multi threads or executing multiple threads at a single time

Javascript is single minded or threaded language, which execute single thread at a time.

Basically asynchronous in better than synchronous, because in many case we have execute multiple threads at a single time. So we need asynchronous to execute multiple threads in programming.
