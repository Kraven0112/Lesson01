Fixing callback hell using fetch in javascript.

fetch() is modern way of fetching data or resources from another server.

fetch() returns promise.

fetch() method accepts parameter like url,object{mathod,headers,body},etc

fetch() is faster than xmlhttprequest because there are .then() and .catch() methods which are known as microtasks and get more priority than other in webAPI in javascript.

All async operation in javascript are handled by webApi in javascript, because javascript has only one thread to handle only one synchronous operation.

when javascript get asynhcronous operation, it passes those async opeartion to a browser's threads to handle.

fetch() method has default requestMethod which is GET method.

.then() method is used to handle resolve of api while using along with fetch() method to retrieve data from server.

.catch() method is used to handle errors while using along with fetch() method. It also return callback to handle error when fetching data gets rejected from another server.
