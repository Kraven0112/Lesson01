ES-6 Module in javascript

module is a way to organize the reusable set of code in javascript.

type="module" is used to set the prototyoe for export and import data explicitly.

There are two types import and export in module : default export and default import

as is used to change name of any import and export data

for default export we use default keyword in module in javascript.

for default import we don't use {} module in javascript.

when set type="module" in script tag , then we cannot access any variables,methods as a global variable in javascript.

And when we set type="module" in script tag it creates module scope in browser.
