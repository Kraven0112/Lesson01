fetch() method in javascript

fetch() method is used to fetch data from one server to another server.

In fetch() method there is GET request method byDefault.

GET request method is used to retrieve data from another server.

POST request method is used to send data for research or for updation in the server.

DELETE request nethod is used to used to remove the resource, such as file or database record from server

In fetch() method when set headers when sendibg data to the srever, it shows the all that data which we send to for updation and research in another server.
